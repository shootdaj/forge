# Plan 15-01: Config and Type Extensions for Session Watchdog

<objective>
Add the watchdog configuration section to ForgeConfigSchema, add the `inactivity_timeout` error category to SDKErrorCategory, and add `last_heartbeat` to ForgeStateSchema. These are the foundational type changes that all subsequent plans depend on.
</objective>

<must_haves>
- Watchdog config section with inactivity_timeout_seconds (default 120), heartbeat_interval_seconds (default 30), max_retries (default 2)
- SDKErrorCategory includes "inactivity_timeout" variant
- ForgeState includes lastHeartbeat field
- All existing tests still pass
</must_haves>

## Tasks

<task id="15-01-01">
<title>Add watchdog config schema section</title>
<read_first>
- src/config/schema.ts (current ForgeConfigSchema, ForgeConfig interface, pattern for nested schemas)
</read_first>
<action>
Add a new `WatchdogConfigSchema` Zod object schema with three fields:
- `inactivity_timeout_seconds`: `z.number().int().min(10).default(120)` — seconds of SDK message inactivity before killing the session
- `heartbeat_interval_seconds`: `z.number().int().min(5).default(30)` — seconds between heartbeat lines to stdout during inactivity
- `max_retries`: `z.number().int().min(0).default(2)` — max times to retry a step after inactivity timeout

Add `watchdog` field to `ForgeConfigSchema` using the established pattern: `watchdog: z.any().default({}).pipe(WatchdogConfigSchema)`

Add the corresponding camelCase TypeScript interface section to `ForgeConfig`:
```typescript
watchdog: {
  inactivityTimeoutSeconds: number;
  heartbeatIntervalSeconds: number;
  maxRetries: number;
};
```
</action>
<acceptance_criteria>
- `src/config/schema.ts` contains `const WatchdogConfigSchema = z.object({`
- `src/config/schema.ts` contains `inactivity_timeout_seconds: z.number().int().min(10).default(120)`
- `src/config/schema.ts` contains `heartbeat_interval_seconds: z.number().int().min(5).default(30)`
- `src/config/schema.ts` contains `max_retries: z.number().int().min(0).default(2)`
- `ForgeConfigSchema` contains `watchdog: z.any().default({}).pipe(WatchdogConfigSchema)`
- `ForgeConfig` interface contains `watchdog:` section with `inactivityTimeoutSeconds`, `heartbeatIntervalSeconds`, `maxRetries`
- `npx vitest run src/config/` exits 0
</acceptance_criteria>
</task>
