## Objective

### Task 2: Add Flutter detection to detectAppType()

<read_first>
- src/uat/runner.ts
- src/uat/types.ts
</read_first>

<action>
In `src/uat/runner.ts`, modify `detectAppType()` to check for Flutter BEFORE the existing stack-based checks. Add an `fs.existsSync` check for `pubspec.yaml` in the project root:

```typescript
import * as path from "node:path";

export function detectAppType(config: ForgeConfig, cwd?: string): AppType {
  // Flutter detection: pubspec.yaml in project root
  if (cwd) {
    const pubspecPath = path.resolve(cwd, "pubspec.yaml");
    if (nodeFs.existsSync(pubspecPath)) {
      return "flutter";
    }
  }

  // Also check testing.stack for explicit "flutter" setting
  const stack = config.testing.stack.toLowerCase();
  if (stack === "flutter" || stack === "dart") {
    return "flutter";
  }

  // ... existing web/api/cli detection unchanged
}
```

The `cwd` parameter is optional to maintain backward compatibility with existing callers. Existing callers that don't pass cwd will still work via the stack-based detection path.

Also add `"flutter"` cases to any switch statements on AppType in runner.ts. For the `buildUATPrompt` switch, add:
```typescript
case "flutter":
  return buildFlutterUATPrompt(workflow, safetyPrompt);
```

For now, `buildFlutterUATPrompt` can be a stub that returns a placeholder prompt string referencing Maestro (Phase 11 will implement it fully).
</action>

<acceptance_criteria>

- `detectAppType()` accepts an optional `cwd` parameter
- `detectAppType()` returns `"flutter"` when pubspec.yaml exists
- `detectAppType()` returns `"flutter"` when `config.testing.stack` is `"flutter"` or `"dart"`
- All switch statements on AppType in runner.ts handle `"flutter"` case (TypeScript compiles without errors)

  const config = makeConfig({
    testing: { ...getDefaultConfig().testing, stack: "dart" },
  });

it("TestDetectAppType_PubspecTakesPriority_OverWebStack", () => {
  mockedExistsSync.mockImplementation((p: fs.PathLike) => {
    return String(p).endsWith("pubspec.yaml");

    testing: { ...getDefaultConfig().testing, stack: "react" },

  expect(detectAppType(config, "/flutter-project")).toBe("flutter");
