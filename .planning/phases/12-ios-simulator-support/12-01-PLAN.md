# Plan 12-01: iOS Simulator Lifecycle and Infrastructure

<objective>
Create the iOS Simulator lifecycle manager (`ios-simulator.ts` and `ios-simulator-types.ts`) mirroring the Android emulator pattern from Phase 10. Add config fields for mobile platform selection and iOS simulator device preference. Add simulator state tracking to forge-state.json schema.
</objective>

<must_haves>
- iOS Simulator boots via `xcrun simctl boot` and readiness is detected by polling device state
- Guaranteed shutdown in try/finally — no orphan simulators after Forge exits
- Config schema has `mobile_platform` and `ios_simulator_device` fields
- State schema tracks simulator UDID and name for crash recovery
- All functions accept injectable `execFn` for unit testing
- Xcode pre-flight check prevents cryptic errors when Xcode is not installed
</must_haves>

```typescript
  constructor(message: string) {
    super(message);
    this.name = "SimulatorError";

export class SimulatorBootTimeoutError extends SimulatorError {
  constructor(public readonly udid: string, public readonly timeoutMs: number) {
    super(`iOS Simulator ${udid} failed to boot within ${timeoutMs}ms. Check that the device exists in Xcode.`);
    this.name = "SimulatorBootTimeoutError";
  }
}

export class SimulatorNotFoundError extends SimulatorError {
  constructor(public readonly deviceName: string) {
    super(`No iOS Simulator found matching '${deviceName}'. Run: xcrun simctl list devices available`);
    this.name = "SimulatorNotFoundError";
  }
}

export class XcodeNotAvailableError extends SimulatorError {
  constructor() {
    super("Xcode command-line tools not found. Install Xcode from the App Store and run: sudo xcode-select --install");
    this.name = "XcodeNotAvailableError";
  }
}
```

### Task 2: Create iOS Simulator Lifecycle Manager

<read_first>
- src/uat/emulator.ts (pattern to mirror: injectable deps, try/finally, withEmulator wrapper)
- src/uat/ios-simulator-types.ts (types created in Task 1)
- src/uat/kvm-check.ts (pattern to mirror for Xcode pre-flight check)
</read_first>

<action>
Create `src/uat/ios-simulator.ts` with these exported functions:

**1. `assertXcodeAvailable(execFn?)`** — Pre-flight check. Runs `xcrun simctl list devices -j`. If command fails, throw `XcodeNotAvailableError`.

**2. `listAvailableSimulators(execFn?): SimulatorDevice[]`** — Parse JSON output of `xcrun simctl list devices available -j`. The JSON structure is:
```json
{ "devices": { "com.apple.CoreSimulator.SimRuntime.iOS-17-5": [{ "udid": "...", "name": "iPhone 15 Pro", "state": "Shutdown", "isAvailable": true }] } }
```
Flatten all runtimes into a single array. Each device gets its `runtime` set from the parent key.

**3. `findBestSimulator(devices: SimulatorDevice[], preferred?: string): SimulatorDevice`** — Selection logic:
- If `preferred` is non-empty, find exact name match (case-insensitive). If not found, throw `SimulatorNotFoundError(preferred)`.
- Otherwise, filter to devices whose name starts with "iPhone" (exclude iPad, Apple Watch, Apple TV).
- Sort by runtime descending (newest iOS first).
- Return first match. If no iPhones available, throw `SimulatorNotFoundError("iPhone")`.

**4. `bootSimulator(options: SimulatorBootOptions): SimulatorHandle`** — Steps:
- Call `assertXcodeAvailable(execFn)`.
- List available simulators via `listAvailableSimulators(execFn)`.
- Find best simulator via `findBestSimulator(devices, options.deviceName)`.
- Run `xcrun simctl boot <udid>` via execFn. Catch errors — if already booted, that's fine.
- Return `SimulatorHandle` with udid, name, runtime, startedAt (ISO string).

**5. `waitForSimulatorReady(handle, options?): Promise<void>`** — Poll `xcrun simctl list devices -j` every `pollIntervalMs` (default 2000ms). Parse JSON, find device by UDID, check if `state === "Booted"`. Timeout after `timeoutMs` (default 120000ms), throw `SimulatorBootTimeoutError`.

**6. `shutdownSimulator(handle, execFn?): Promise<void>`** — Run `xcrun simctl shutdown <udid>`. Never throws — catch errors silently (idempotent).

**7. `registerSimulatorCleanup(handle): () => void`** — Attach `process.on('exit')`, `process.on('SIGINT')`, `process.on('SIGTERM')` handlers that call `execSync('xcrun simctl shutdown <udid>')`. Return deregister function.

**8. `withSimulator<T>(options, callback): Promise<T>`** — High-level wrapper:
```typescript
const handle = bootSimulator(options);
const deregister = registerSimulatorCleanup(handle);
try {
  await waitForSimulatorReady(handle, { timeoutMs: options.timeoutMs, pollIntervalMs: options.pollIntervalMs, execFn: options.execFn });
  return await callback(handle);
} finally {
  deregister();
  await shutdownSimulator(handle, options.execFn);
}
```

All functions use injectable `execFn` defaulting to `execSync(cmd, { encoding: "utf-8" })`.
</action>
