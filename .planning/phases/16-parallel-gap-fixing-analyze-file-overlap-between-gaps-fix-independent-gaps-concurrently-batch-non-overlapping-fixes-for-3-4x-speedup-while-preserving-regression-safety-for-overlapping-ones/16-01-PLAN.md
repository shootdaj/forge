<task id="1">
<title>Create gap-graph.ts with conflict graph and coloring utilities</title>
<read_first>
- src/pipeline/spec-compliance.ts (understand gap data structures and how gaps are used)
- src/pipeline/types.ts (understand existing type patterns)
</read_first>
<action>
Create `src/pipeline/gap-graph.ts` with the following exports:

1. **Type: `GapWithFiles`** — extends gap info with file list:
```typescript
export interface GapWithFiles {
  id: string;
  description: string;
  files: string[];
}
```

2. **Function: `buildConflictGraph(gaps: GapWithFiles[]): Map<string, Set<string>>`**
   - Takes an array of gaps with their associated files
   - Returns an adjacency map where keys are gap IDs and values are sets of conflicting gap IDs
   - Two gaps conflict if they share at least one file (case-insensitive path comparison)
   - Gaps with empty files arrays are treated as conflicting with ALL other gaps (conservative fallback per D-09)
   - Algorithm: for each pair of gaps, check file set intersection

3. **Function: `colorGraph(adjacencyMap: Map<string, Set<string>>): Map<number, string[]>`**
   - Takes the conflict graph adjacency map
   - Returns a map from color number (0-based) to array of gap IDs assigned that color
   - Uses greedy graph coloring: iterate nodes in order of decreasing degree, assign smallest color not used by neighbors
   - Gaps with same color are independent (no shared files) and can run concurrently

4. **Function: `analyzeGapOverlap(gaps: GapWithFiles[]): string[][]`**
   - Convenience function combining buildConflictGraph + colorGraph
   - Returns an array of arrays: each inner array is a group of gap IDs that can be fixed concurrently
   - Groups are ordered by color number (arbitrary but deterministic)
   - If all gaps have empty file lists, returns a single group with all gap IDs (all sequential)

5. **Function: `limitConcurrency<T>(tasks: (() => Promise<T>)[], maxConcurrent: number): Promise<PromiseSettledResult<T>[]>`**
   - Generic concurrency limiter using Promise.allSettled semantics
   - Executes at most `maxConcurrent` tasks simultaneously
   - Returns results in the same order as input tasks
   - Implementation: maintain a pool of active promises, start new ones as others complete
</action>
<acceptance_criteria>
- File `src/pipeline/gap-graph.ts` exists
- `gap-graph.ts` exports `buildConflictGraph`, `colorGraph`, `analyzeGapOverlap`, `limitConcurrency`, and `GapWithFiles`
- `buildConflictGraph` with gaps sharing file "src/app.ts" produces an edge between those gaps
- `buildConflictGraph` with a gap having empty files[] produces edges to all other gaps
- `colorGraph` with independent gaps (no edges) assigns them all color 0 (same group)
- `colorGraph` with fully connected gaps (all share files) assigns each a different color
- `analyzeGapOverlap` returns `string[][]` where each inner array has no gaps that share files
- `limitConcurrency` runs at most N tasks at a time (verifiable by timing or counter)
</acceptance_criteria>
</task>
