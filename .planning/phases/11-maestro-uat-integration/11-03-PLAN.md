# Plan 11-03: Test Pyramid — Unit, Integration, and Scenario Tests

<objective>
Create comprehensive tests at all three tiers for the Phase 11 Maestro UAT integration. Unit tests cover flutter-run.ts and maestro.ts in isolation with mocked deps. Integration tests verify the flutter run lifecycle, Maestro JUnit parsing with real XML samples, and the UAT runner's Flutter path routing. Scenario tests verify the full end-to-end flow: emulator + flutter run + maestro test + gap closure.
</objective>

- `TestFlutterRun_StopSendsSigterm` — verify process.kill called with SIGTERM

- `TestFlutterRun_StopNeverThrows` — mock process.kill throwing, verify no exception propagated

**Test: withFlutterRun**
- `TestFlutterRun_WithFlutterRunCallsCallback` — verify callback invoked after ready signal
- `TestFlutterRun_WithFlutterRunCleansUpOnSuccess` — verify stop called after callback completes
- `TestFlutterRun_WithFlutterRunCleansUpOnFailure` — verify stop called even when callback throws
- `TestFlutterRun_WithFlutterRunPropagatesCallbackError` — verify callback errors re-thrown after cleanup

**Scenario 1: TestMaestroUAT_FullPassingFlow**
Simulate a complete Flutter UAT pass:
1. Set up config with `stack: "flutter"`, `maestroFlowsDir: ".maestro"`, `flutterAvdName: "test-avd"`
2. Mock all external deps (emulator, flutter run, maestro) to succeed

5. Verify: result.status === "passed", result.workflowsTested > 0, result.workflowsPassed > 0

**Scenario 2: TestMaestroUAT_GapClosureFixesFailures**
Simulate gap closure fixing a Maestro failure:
1. Set up config, mock emulator/flutter run to succeed
2. First maestro run: return 1 failure
3. Mock gap closure step succeeding
4. Second maestro run: return all passing
5. Verify: result.status === "passed", result.attemptsUsed === 2

**Scenario 3: TestMaestroUAT_DefenseInDepthTrustsXmlOverExitCode**
Simulate the Maestro regression:
1. Mock maestro CLI returning exit code 1
2. Mock JUnit XML showing all tests pass
3. Verify: reconciled result is PASS (trusts XML)

**Scenario 4: TestMaestroUAT_EmulatorFailureIsNonFatal**

1. Mock emulator start throwing EmulatorStartError

1. Mock first maestro run failing
