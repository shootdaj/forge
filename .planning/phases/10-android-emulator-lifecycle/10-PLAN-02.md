**`startEmulator(options: EmulatorStartOptions): EmulatorHandle`**

Implementation:
1. Call `assertKvmAvailable()` first — throws KvmUnavailableError if unavailable
2. Get list of currently running emulators via `adb devices` (parse for `emulator-NNNN` lines)
3. Spawn emulator process:
   ```typescript
   const args = [
     "-avd", options.avdName,
     "-no-audio",
     "-no-window",
     "-gpu", "swiftshader_indirect",
     "-no-boot-anim",
     "-no-snapshot-save",
   ];
   const emulatorSpawn = options.spawnFn ?? spawn;
   const child = emulatorSpawn("emulator", args, {
     detached: true,
     stdio: "pipe",
   });
   ```
4. Store `child.pid` immediately (before waiting for boot — enables cleanup if boot fails)
5. Attach error listener on child to detect early exit:
   ```typescript
   child.on("error", (err) => { /* log error */ });
   child.on("exit", (code) => { /* set earlyExit flag */ });
   ```
6. Wait up to 30 seconds for a new serial to appear in `adb devices` that wasn't in the initial list
7. Return `EmulatorHandle` with pid, serial, avdName, startedAt (ISO string), and process reference
8. If emulator exits before serial appears, throw `EmulatorStartError`

Use `options.execFn ?? ((cmd: string) => execSync(cmd, { encoding: "utf-8" }))` for all adb commands.

**Helper `listEmulatorSerials(execFn): string[]`** — parses `adb devices` output, returns array of `emulator-NNNN` serials where status is "device" (not "offline").
</action>

<task id="02" name="Implement boot readiness polling">

<action>
Add `waitForBoot` to `src/uat/emulator.ts`:

**`waitForBoot(handle: EmulatorHandle, options?: BootWaitOptions): Promise<void>`**

Implementation:
1. Set defaults: `timeoutMs = options?.timeoutMs ?? 180_000`, `pollIntervalMs = options?.pollIntervalMs ?? 3_000`
2. Set `execFn = options?.execFn ?? ((cmd) => execSync(cmd, { encoding: "utf-8" }))`
3. Record `startTime = Date.now()`
4. Poll loop:
   ```typescript
   while (Date.now() - startTime < timeoutMs) {
     try {
       const result = execFn(`adb -s ${handle.serial} shell getprop sys.boot_completed`);
       if (result.trim() === "1") {
         return; // Boot complete!
       }
     } catch {
       // adb command failed — device not ready yet, continue polling
     }
     await new Promise((resolve) => setTimeout(resolve, pollIntervalMs));
   }
   ```
5. If loop exits without boot: throw `EmulatorBootTimeoutError` with serial and timeoutMs
6. Log each poll attempt at debug level: `Waiting for emulator ${handle.serial} boot... (${elapsed}ms/${timeoutMs}ms)`

Do NOT use `adb wait-for-device` — it fires during early boot before system is ready. Only `sys.boot_completed=1` is reliable.
</action>
<acceptance_criteria>
- `src/uat/emulator.ts` contains exported function `waitForBoot`
- Function polls `adb -s <serial> shell getprop sys.boot_completed`
- Returns when result is `"1"` (trimmed)
- Throws `EmulatorBootTimeoutError` after timeoutMs
- Default timeout is 180000ms (180 seconds)
- Default poll interval is 3000ms (3 seconds)
- Uses injectable `execFn` for testing
</acceptance_criteria>

<action>
Add `stopEmulator` and cleanup helpers to `src/uat/emulator.ts`:

**`stopEmulator(handle: EmulatorHandle, execFn?): Promise<void>`**

Implementation:
1. Try graceful shutdown: `adb -s ${handle.serial} emu kill`
2. Wait up to 5 seconds for process to exit (check with `process.kill(handle.pid, 0)`)
3. If still alive after 5 seconds: `process.kill(handle.pid, "SIGKILL")`
4. Catch all errors silently — teardown must never throw (log warnings instead)

**`registerCleanupHandler(handle: EmulatorHandle): () => void`**

Implementation:
1. Create cleanup function that calls `process.kill(handle.pid, "SIGKILL")` wrapped in try/catch
2. Register on `process.on("exit", cleanup)` and `process.on("SIGINT", cleanup)` and `process.on("SIGTERM", cleanup)`
3. Return a deregister function that removes the handlers (for clean test isolation)

**`withEmulator<T>(options: EmulatorStartOptions, callback: (handle: EmulatorHandle) => Promise<T>): Promise<T>`**

High-level wrapper:
```typescript
export async function withEmulator<T>(
  options: EmulatorStartOptions,
  callback: (handle: EmulatorHandle) => Promise<T>,
): Promise<T> {
  const handle = startEmulator(options);
  const deregister = registerCleanupHandler(handle);
  try {
    await waitForBoot(handle, {
      timeoutMs: options.timeoutMs,
      pollIntervalMs: options.pollIntervalMs,
      execFn: options.execFn,
    });
    return await callback(handle);
  } finally {
    deregister();
    await stopEmulator(handle, options.execFn);
  }
}
```

This is the primary interface Phase 11 will use.
</action>

<action>
Add `killOrphanEmulators` to `src/uat/emulator.ts`:

**`killOrphanEmulators(stateManager?: StateManager, execFn?): Promise<string[]>`**

Implementation:
1. Get currently running emulators via `listEmulatorSerials(execFn)`
2. If no emulators running: return empty array (fast path)
3. If stateManager provided:
   a. Load state, read `emulator.pid` and `emulator.serial`
   b. If stored serial matches a running emulator: kill it via `adb -s <serial> emu kill`
   c. If stored PID is still alive (`process.kill(pid, 0)` doesn't throw): send SIGKILL
   d. Clear emulator state: `stateManager.update(s => ({ ...s, emulator: { pid: 0, serial: "", avdName: "", startedAt: undefined } }))`
4. For any REMAINING running emulators not in state (belt-and-suspenders):
   a. Kill via `adb -s <serial> emu kill`
5. Return array of killed serial strings
6. Log each kill action: `Killed orphan emulator: ${serial}`
7. Wrap everything in try/catch — orphan cleanup failure is non-fatal (log warning)

**`persistEmulatorState(handle: EmulatorHandle, stateManager: StateManager): Promise<void>`**

Helper to save emulator info to forge-state.json:
```typescript
await stateManager.update((state) => ({
  ...state,
  emulator: {
    pid: handle.pid,
    serial: handle.serial,
    avdName: handle.avdName,
    startedAt: handle.startedAt,
  },
}));
```

**`clearEmulatorState(stateManager: StateManager): Promise<void>`**

Helper to clear emulator state after teardown:
```typescript
await stateManager.update((state) => ({
  ...state,
  emulator: {
    pid: 0,
    serial: "",
    avdName: "",
    startedAt: undefined,
  },
}));
```
</action>
